# Priyani Mohanta — Engineering Portfolio (Frontend)

The frontend foundation for Priyani Mohanta's personal engineering portfolio, built with React, TypeScript, Vite, and an engineering-centric design system (Deep Graphite, Restrained Electric Lime, Technical Typography).

## Tech Stack
- **Framework:** React 18
- **Language:** TypeScript (Strict Mode)
- **Bundler:** Vite
- **Styling:** Custom CSS with engineering design tokens
- **Icons:** Lucide React

## Setup & Running Locally

### 1. Prerequisites
Ensure **Node.js** (v20 or v22 LTS recommended) and **npm** are installed on your machine.
Verify with:
```bash
node -v
npm -v
```

### 2. Install Dependencies
Navigate into the `client/` directory and install packages:
```bash
cd client
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` to preview the portfolio.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be output to `client/dist/`.
